# Monarchy agent instructions

Read `PROJECT.md` completely before inspecting, diagnosing, or changing
Monarchy. Keep `PROJECT.md` updated whenever behavior, paths, calibration,
safety constraints, timing, supported targets, release/update behavior, or
troubleshooting findings change materially.

For Windows work, use `windows/README.md` for build and release instructions.
Preserve the portable `data` directory during upgrades and never package its
contents into a release.
